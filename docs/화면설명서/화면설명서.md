## 1. 서비스 개요

**Tikkle(티끌)** 은 "잔돈으로 시작하는 나만의 코인 투자" 서비스입니다.

- 사용자의 **케이뱅크 카드** 결제가 발생하면(케이뱅크 앱 푸시 알림 수집 방식), 설정된 잔돈 규칙(올림/비율)에 따라 잔돈을 계산합니다.
- 계산된 잔돈은 케이뱅크 계좌에서 출금되어 **업비트(Upbit)** 로 입금되고, AI가 사용자의 투자 성향에 맞춰 추천한 코인을 시장가로 매수합니다.
- 매매 방식은 **자동 투자**(전 과정 자동 실행)와 **수동 승인**(대기 중 건을 사용자가 직접 승인/취소) 두 가지 흐름을 지원합니다.
- 잔돈이 **5,100원 미만**이면 투자가 진행되지 않습니다(업비트 최소 주문 금액 대응 정책).

## 3. 공통 UI 및 공통 정책

### 3.1 하단 탭 바 (Bottom Navigation)

- 메인 4개 화면(홈 / 결제내역 / 인사이트 / 설정)에 항상 고정 노출. 활성 탭은 브랜드 컬러(파란색)로 표시.
- **결제내역 탭 빨간 점 뱃지**: 승인 대기 중(PENDING)인 결제 건이 1건 이상이면 아이콘 우상단에 빨간 점을 표시. 어느 탭에서든 대시보드 데이터를 로드해 즉시 반영된다.

### 3.2 색상 규칙 (손익 표기)

- **수익/상승 = 빨간색(+)**, **손실/하락 = 파란색(−)** — 국내 금융 UI 관례를 따른다.
- 브랜드 컬러: `#0051ff` (파란색). 주요 CTA 버튼, 활성 상태, 강조 텍스트에 사용.

### 3.3 바텀시트 공통 동작

모든 바텀시트(모달)는 다음 세 가지 방법으로 닫힌다.

1. 우측 상단 `X` 버튼 탭
2. 시트 바깥 딤(dim) 영역 탭
3. 안드로이드 뒤로가기 버튼 (시트만 닫히고 화면은 유지)

### 3.4 로딩 / 빈 상태 / 에러 패턴

- **로딩**: 첫 데이터 도착 전에는 스켈레톤 UI(홈 자산 카드, 결제내역) 또는 스피너를 노출. 버튼 동작 중에는 버튼 내부에 스피너 + "저장 중...", "검증 중..." 등의 라벨로 전환되고 중복 탭이 방지된다.
- **빈 상태**: 데이터가 없으면 안내 문구를 노출한다. (예: "이번 달 소비 내역이 없어요.", "아직 보유한 코인이 없어요.", "등록된 글이 없습니다")
- **에러**: 화면 하단 또는 해당 영역에 빨간색 에러 문구를 노출하고, 사용자가 재시도할 수 있는 상태를 유지한다.

## 4. 인증 (AUTH)

### AUTH-01. 로그인

<img src="1.jpg" width="260">

- **라우트**: `/login` (비로그인 전용)
- **개요**: 앱 진입 화면. 전화번호 + 비밀번호 방식의 자체 로그인. 저장된 토큰이 유효하면 이 화면을 거치지 않고 자동 로그인된다.

**UI 구성 및 동작**

1. **브랜드 영역**: Tikkle 로고, 타이틀, 슬로건("잔돈으로 시작하는 나만의 코인 투자")
2. **전화번호 입력**: `-` 없이 숫자만 입력 (숫자 키패드)
3. **비밀번호 입력**: 마스킹 처리, Enter 키로도 로그인 제출 가능
4. **[로그인] 버튼**: 두 필드가 모두 입력되어야 활성화. 처리 중에는 "로그인 중..." + 스피너 표시
5. **회원가입 링크**: "아직 계정이 없으신가요? **회원가입**" → AUTH-02로 이동
6. **약관 고지**: "계속 진행하면 Tikkle의 이용약관 및 개인정보 처리방침에 동의합니다."

**에러 메시지**

| 서버 에러 코드 | 노출 문구 |
| --- | --- |
| `USER_NOT_FOUND` | 가입되지 않은 전화번호입니다. |
| `INVALID_PASSWORD` | 비밀번호가 일치하지 않습니다. |
| 그 외 | 로그인 중 오류가 발생했습니다. |

**이동**: 로그인 성공 시 온보딩 완료 여부에 따라 홈(`/`) 또는 온보딩(`/onboarding`)으로 이동.

### AUTH-02 ~ 04. 회원가입 (3단계)

<img src="2.jpg" width="230"> <img src="3.jpg" width="230"> <img src="4.jpg" width="230">

- **라우트**: `/signup` (단일 라우트 내 3단계 전환)
- **개요**: 전화번호 SMS 인증 기반 회원가입. 상단 진행 바가 단계에 따라 1/3씩 채워진다.
- **헤더 뒤로가기(`<`)**: 2·3단계에서는 이전 단계로, 1단계에서는 로그인 화면으로 돌아간다.

**AUTH-02. [1/3단계] 전화번호 입력** (스크린샷 2)

- 타이틀 "전화번호를 입력해 주세요" / 서브 "인증 문자를 발송할게요."
- 전화번호 입력 필드 (가이드: "'-' 기호 없이 숫자만 입력하세요")
- **[인증번호 받기]**: 탭 시 인증 문자 발송 API 호출 → 성공 시 2단계로 전환

**AUTH-03. [2/3단계] 인증번호 입력** (스크린샷 3)

- 입력한 전화번호를 타이틀 영역에 표시하고 "발송된 6자리 인증번호를 입력하세요." 안내
- 인증번호 6자리 입력 필드 (가이드: "인증번호는 3분간 유효합니다")
- **[인증번호 재발송]** 텍스트 링크: 동일 번호로 인증 문자를 다시 발송
- **[인증 확인]**: 6자리 입력 시 검증 API 호출 → 성공 시 가입 토큰(signupToken)을 받고 3단계로 전환

**AUTH-04. [3/3단계] 정보 입력** (스크린샷 4)

- 입력 필드: **이름**, **비밀번호**(가이드: 영문+숫자+특수문자 포함 8자 이상), **비밀번호 확인**
- 비밀번호와 확인 값이 다르면 가입 진행 불가
- **[가입하기]**: 성공 시 자동 로그인되어 온보딩(`/onboarding`)으로 이동

**에러 메시지**

| 서버 에러 코드 | 노출 문구 |
| --- | --- |
| `SMS_SEND_FAILED` | 문자 발송에 실패했습니다. 번호를 확인해 주세요. |
| `INVALID_VERIFICATION_CODE` | 인증번호가 틀리거나 만료되었습니다. |
| `EXPIRED_SIGNUP_TOKEN` | 인증 시간이 만료되었습니다. 다시 시도해 주세요. |
| `PHONE_ALREADY_REGISTERED` | 이미 가입된 전화번호입니다. |

## 5. 온보딩 (ONB)

- **라우트**: `/onboarding` (단일 라우트 내 8단계 전환)
- **공통 UI**: 상단에 "N / 8 단계" 텍스트와 진행률(%) 및 진행 바. 하단 고정 영역에 **[다음]**(단계별 활성화 조건 충족 시 파란색) / **[이전]**(2단계부터 노출) 버튼.
- **단계별 즉시 저장**: 1단계(카드)와 2단계(업비트 키)는 [다음] 탭 시점에 서버에 즉시 저장·검증되고, 실패하면 에러 문구와 함께 해당 단계에 머문다. 설문(3~7단계)은 7단계 완료 시 일괄 제출된다.
- **부분 완료 재진입**: 온보딩 도중 이탈한 사용자는 재로그인 시 첫 미완료 단계부터 재개한다. (카드 미등록 → 1단계, 업비트 미연동 → 2단계, 성향 미입력 → 3단계)
- **업비트 키 만료 재연동 모드**: 기존 가입자의 업비트 키만 만료된 경우 2단계로 진입하며, 상단에 빨간 경고 배너("보안을 위해 업비트 권한이 만료되었습니다. 업비트 API 키를 다시 연동해 주세요.")가 표시된다. 재연동 완료 시 나머지 단계를 건너뛰고 바로 홈으로 이동한다.

### ONB-01. [1/8] 케이뱅크 카드 등록 (13%)

<img src="5.jpg" width="260">

- **개요**: 잔돈 적립의 기준이 되는 케이뱅크 카드를 등록한다. 케이뱅크 카드로 결제가 발생하면 해당 계좌에서 잔돈이 자동 이체된다.

**UI 구성 및 동작**

1. **안내 배너 (파란색)**: "케이뱅크 카드 자동 연동 — 현재 케이뱅크 카드만 지원됩니다"
2. **케이뱅크 앱 푸시 알림 필수 안내**: 결제 수집이 케이뱅크 앱의 결제 푸시 알림 기반이므로 알림이 꺼져 있으면 동작하지 않는다. 설정 경로를 단계별로 안내: `'케이뱅크' 앱 실행 → 전체 → 설정 → 알림 → '카드' 알림 ON`
3. **카드 번호 끝 4자리 입력**: 숫자 4자리(placeholder "0000"). 정확히 4자리 숫자가 입력되어야 [다음] 활성화
4. **[다음]**: 카드 정보를 서버에 저장("저장 중...") 후 2단계로 이동

### ONB-02. [2/8] 업비트 계정 연결 (25%)

<img src="6.jpg" width="260"> <img src="7.jpg" width="260">

- **개요**: 잔돈 투자를 실행할 업비트 Open API 키를 연동하고, 업비트 입금 시 사용할 2차 인증 앱을 선택한다.

**UI 구성 및 동작**

1. **가이드 아코디언 2종** (탭 시 펼침/접힘)
   - **API 키 발급 가이드**: PC 환경에서 업비트 Open API 페이지 접속 → 권한 체크(자산조회 · 주문조회 · 주문하기 · 입금조회 · 입금하기) → 서버 IP(`34.64.106.45`) 등록 → 키 발급·복사 순서를 단계별로 안내
   - **2차 인증 설정 가이드**: 업비트 앱에서 2채널 인증(카카오톡 · 네이버 · 하나인증서 중 택1)을 활성화하는 경로 안내
2. **Access Key / Secret Key 입력**: placeholder "…를 붙여넣으세요". Secret Key는 마스킹 처리
3. **2차 인증 앱 선택**: `카카오톡` / `네이버` / `하나원큐` 3개 카드 중 단일 선택. 하단 안내 "업비트 입금 시 이 앱으로 2차 인증이 요청됩니다."

<img src="14.png" width="260">

## 7. 결제 내역 & 잔돈 투자 (PAY)

### PAY-01. 결제 내역

<img src="15.jpg" width="260"> <img src="16.jpg" width="260">

- **라우트**: `/payments` (하단 탭: 결제내역)
- **개요**: 케이뱅크 카드 결제 내역과 각 결제에서 발생한 잔돈의 투자 상태를 월 단위로 조회·관리한다. 화면의 모든 수치는 선택된 월 기준이다.

**UI 구성 및 동작**

1. **월 선택 버튼**: `YYYY년 M월 ∨` — 탭 시 조회 기간 선택 바텀시트(PAY-02) 노출. 월 변경 시 요약·차트·내역이 모두 갱신된다.
2. **월간 요약 카드 3종**
   - **총 결제 금액** (흰색 카드): 해당 월 누적 카드 결제액
   - **투자된 잔돈** (파란색 강조): 실제 코인 매수까지 완료된 잔돈 합계
   - **미투자 잔돈** (노란색 강조): 발생했지만 투자되지 않은 잔돈 합계
3. **소비 카테고리 막대그래프**: 카테고리(카페/마트/식비/쇼핑/교통/문화/기타)별 지출액을 가로 막대로 표시. 최대 지출 카테고리를 기준으로 상대 길이가 결정되며, '기타'는 항상 마지막에 배치. 내역이 없으면 "이번 달 소비 내역이 없어요."
4. **최근 내역 리스트**
   - **상태 필터 칩**: `전체` / `투자 완료` / `대기 중` / `취소` — 서버 사이드 필터로, 선택 시 목록을 다시 불러온다. `대기 중` 칩에는 대기 건수 뱃지가 붙는다 (10건 이상이면 "9+", 빨간 배경 · 칩 활성 시 흰 배경)
   - **리스트 아이템 구성**
     - 좌측: 카테고리 아이콘 — **탭하면 카테고리 변경 바텀시트(PAY-03) 노출**
     - 중앙: 결제처명, 카테고리 · 결제일(MM.DD)
     - 우측: 결제 금액, 잔돈 금액 + 상태 표시
   - **상태별 우측 표시**

     | 상태 | 표시 |
     | --- | --- |
     | 투자 완료 (INVESTED) | 파란 코인 칩 `● 코인명` + 아래 줄에 `수량개 · ₩체결단가` |
     | 대기 중 (PENDING) | 노란 `대기 중` 뱃지 + **승인 마감까지 남은 시간 카운트다운** (예: "13시간 59분 남음") |
     | 투자 취소 (CANCELED) | `투자 취소` 뱃지 |
     | 만료 (EXPIRED) | `만료` 뱃지 |

   - **대기 중 행 탭** → 해당 건의 정보를 가지고 잔돈 투자 확인 화면(PAY-04)으로 이동 (다른 상태의 행은 탭 동작 없음)
   - **무한 스크롤**: 목록 하단 도달 시 다음 페이지 자동 로드 ("불러오는 중…")
5. **하단 탭 바**: [결제내역] 활성. 대기 건 존재 시 탭 아이콘에 빨간 점

### PAY-02. [시트] 조회 기간 선택 — 스크린샷 없음

### SET-02. 자동 투자 설정

<img src="25.jpg" width="260">

- **라우트**: `/settings/investment`
- **개요**: 잔돈 자동 투자 서비스 전체를 켜고 끄는 화면.

**UI 구성 및 동작**

1. **토글 카드**: "자동 투자 서비스 — 잔돈 자동 코인 투자 기능" + 토글 스위치. 하단에 현재 상태 라벨(`● 서비스 이용 중` 파란색 / `서비스 중단 중` 회색)
2. **끌 때 (On → Off)**: 즉시 꺼지지 않고 **중단 확인 바텀시트**가 먼저 노출된다.

3. **켤 때 (Off → On)**: 확인 없이 즉시 저장
4. **중단 상태**: 토글 카드 아래에 동일한 경고 문구의 빨간 안내 박스가 상시 노출
5. **설명 카드**: "자동 투자란?" — 결제 발생 시 잔돈을 자동으로 코인에 투자하며, On 상태면 결제 내역 수집부터 투자 실행까지 전 과정이 자동으로 진행된다는 설명

### SET-03. 잔돈 규칙 설정 (카테고리별)

<img src="26.jpg" width="260">

- **라우트**: `/settings/category-rules`
- **개요**: 온보딩에서 일괄 적용한 잔돈 규칙을 **카테고리별로 다르게** 커스텀하는 화면.

**UI 구성 및 동작**

1. **정책 고지**: "※ 5,100원 미만의 잔돈이 발생하면 투자가 진행되지 않습니다."
2. **카테고리 리스트 (7종)**: 이모지 아이콘 + 카테고리명 + 현재 규칙 뱃지 + `>` 화살표
   - 카테고리: ☕ 카페·디저트 / 🏪 편의점·마트 / 🍽️ 식사·배달 / 🛍️ 쇼핑 / 🚌 교통·주유 / 🎬 문화·여가 / 📦 기타
   - 규칙 뱃지 표기 예: `20% 적립`, `10,000원 단위 올림`

3. **행 탭** → 해당 카테고리의 규칙 편집 바텀시트(SET-04) 노출
4. **[저장]** (하단 고정): 서버 값과 달라진 카테고리가 하나라도 있어야 활성화. 탭 시 7개 카테고리 규칙을 일괄 저장("저장 중...")

### SET-04. [시트] 카테고리 잔돈 규칙 편집 — 스크린샷 없음

- 헤더에 선택한 카테고리(`🚌 교통·주유 잔돈 규칙` 형식) 표시.

- 시트에서 조절한 값은 닫는 즉시 목록 뱃지에 반영되며, 실제 서버 저장은 SET-03의 [저장] 버튼에서 일괄 수행된다.

### SET-05. 투자 성향 및 관심 테마 — 스크린샷 없음

- **라우트**: `/settings/investment-profile`

- 온보딩과 동일한 5개 문항이 **한 페이지에 세로로 나열**되며, 진입 시 서버에 저장된 기존 선택값이 미리 선택되어 있다.
- **[저장하기]** (하단 고정): 관심 테마를 1개도 선택하지 않으면 "관심 테마를 하나 이상 선택해 주세요." 에러. 성공 시 "투자 성향이 업데이트되었습니다." 문구 노출.

### SET-06. 케이뱅크 카드 관리 — 스크린샷 없음

- **라우트**: `/settings/kbank-card`
- **개요**: 잔돈이 출금될 케이뱅크 카드를 변경하는 화면.

**UI 구성 및 동작**

1. **현재 등록된 카드**: `•••• 1234` 형식으로 마스킹 표시 (조회 실패 시 에러 문구)
2. **카드 번호 확인 안내 배너**: "케이뱅크 앱 → 카드 → 카드 정보에서 카드 번호를 확인할 수 있어요."
3. **푸시 알림 필수 안내**: 온보딩 1단계와 동일한 케이뱅크 앱 알림 설정 경로 안내
4. **카드 번호 끝 4자리 입력** + **[저장하기]**: 숫자 4자리 검증 후 저장. 성공 시 "케이뱅크 카드가 업데이트되었습니다." 노출 및 입력 필드 초기화

### SET-07. 업비트 계정 관리 — 스크린샷 없음

- **라우트**: `/settings/api-key`
- **개요**: 업비트 Open API 키와 2차 인증 수단을 재등록하는 화면. 키 만료 시(홈/투자 플로우에서 안내됨) 재연동 진입점이기도 하다.

**UI 구성 및 동작**

1. **타이틀**: "업비트 계정을 변경해 주세요" — 새 키 입력 시 즉시 업데이트됨을 안내

3. **입력 폼**: Access Key / Secret Key(마스킹) / 2차 인증 수단(카카오톡·네이버·하나원큐 중 택1)
4. **[저장하기]**: 세 항목 모두 입력해야 하며("모든 항목을 입력해 주세요."), 성공 시 "업비트 계정 정보가 업데이트되었습니다." 노출 후 보안을 위해 Secret Key 입력값은 비워진다

### SET-08. [시트] 개인정보 처리방침 / 이용약관 — 스크린샷 없음

- **[취소]**: 시트 닫기

## 10. 부록 — 데이터 정의 및 정책 요약

### 10.1 잔돈 규칙 (RuleType)

| 방식 | 옵션 | 계산 방법 |
| --- | --- | --- |
| 올림 적립 | 1만 / 2만 / 3만 / 4만 / 5만 원 | 결제 금액을 해당 단위로 올림한 차액을 잔돈으로 적립 |
| 비율 적립 | 10 / 15 / 20 / 25 / 30 % | 결제 금액의 해당 비율을 잔돈으로 적립 |

- 온보딩(ONB-08)에서는 전 카테고리 공통으로 1개 규칙을 적용하고, 설정(SET-03)에서 카테고리별로 개별 변경할 수 있다.
- **최소 투자 금액 정책**: 산출된 잔돈이 **5,100원 미만**이면 해당 결제 건은 투자가 진행되지 않는다.

### 10.3 결제 건 상태 (TransactionStatus)

| 코드 | 표기 | 의미 |
| --- | --- | --- |
| INVESTED | 투자 완료 | 잔돈으로 코인 매수 체결 완료 (코인명·수량·체결단가 표시) |
| PENDING | 대기 중 | 수동 승인 대기. 마감 시각까지 남은 시간 카운트다운 표시 |
| CANCELED | 투자 취소 | 사용자가 취소했거나 입금/매수 실패·인증 초과로 취소 처리됨 |

### 10.4 투자 성향 프로필
