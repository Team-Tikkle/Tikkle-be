## 5. 투자 및 매매 시스템 엔진 (SYS)

결제 알림 수신 이후 카테고리 분류, 다이나믹 잔돈 계산, 시장 시간에 따른 하이브리드 매매 및 배치 제어를 담당하는 백엔드 코어 기능입니다.

| 기능 ID | 기능명 | 설명 | 사전 조건 | 정상 흐름 (Happy Path) | 예외 및 에러 처리 / 데이터 힌트 |
| --- | --- | --- | --- | --- | --- |
| **FEAT-SYS-001** | 결제 푸시 이벤트 보안 검증 | 안드로이드 앱이 스크래핑하여 전송한 결제 이벤트 데이터의 무결성과 보안을 검증합니다. | 푸시 알림 감지 및 서버 전송 완료 | 1. 결제 푸시 이벤트 데이터 서버 수신 <br>2. 요청 헤더에서 타임스탬프 및 암호화 서명 추출 <br>3. 전송 지연 시간(5분 이내) 확인 및 HMAC SHA-256 서명 무결성 검증 통과 | **[예외]** 타임아웃 만료 시 전송 지연 오류(401) 처리 <br>**[예외]** 서명 불일치 시 데이터 변조로 간주하여 차단 |
| **FEAT-SYS-002** | 3단계 Fail-Fast 트래픽 필터링 | 투자 가치가 없는 무의미한 결제 트래픽을 선제적으로 차단하여 시스템 자원을 보호합니다. | FEAT-SYS-001 보안 검증 통과 | 1. [중복 차단] 결제 고유 식별자(transactionId) 기반 중복 수신 여부 판별 <br>2. [카드 매칭] 사용자가 온보딩 시 지정한 투자 타겟 카드와 결제 카드 일치 여부 판별 (불일치 시 로직 조기 종료) <br>3. 필터링 완료 건에 한해 결제 이벤트 원장 최초 적재 | **[중복]** 이미 처리된 식별자일 경우, 후속 처리를 중단하되 클라이언트에게는 정상 접수(Idempotent) 응답을 반환하여 재시도를 방지함. |
| **FEAT-SYS-003** | 2-Tier 카테고리 분류 및 하이브리드 정산 | 캐시와 비동기 AI를 혼합하여 가맹점을 분류하고, 확정된 카테고리의 룰에 따라 잔돈을 다이나믹하게 정산합니다. | FEAT-SYS-002 필터링 통과 | 1. [1차 분류] 인메모리 캐시에서 가맹점명 전방 일치 검색 <br>2. [Cache HIT] 카테고리 즉시 확정 -> 유저의 해당 카테고리 잔돈 규칙 매핑 및 계산 -> [0원 필터링] (금액 존재 시 Market Time Gate 분기 진입) <br>3. [Cache MISS] 원장 상태를 CLASSIFYING(분류 중)으로 저장 후 비동기 분류 대기열 등록 -> 백그라운드 AI가 카테고리 확정 -> 캐시 업데이트 및 잔돈 계산 -> Market Time Gate 분기 진입 | **[예외]** 잔돈 계산 결과가 0원일 경우 원장에 NOT_INVESTED 저장 후 로직 종료. <br> **[예외]** 외부 AI API 통신 장애 시 '기타(ETC)' 카테고리로 강제 할당 후 정산 진행. |
| **FEAT-SYS-004** | Market Time Gate 및 최종 상태 전이 | 잔돈 정산이 완료된 주문을 주식 시장 개장 여부와 유저의 매매 모드에 따라 분기 처리합니다. | FEAT-SYS-003 정산 완료 | 💡 [최종 분기 로직] <br>1. 장외 시간 결제: 즉시 매수하지 않고 PENDING(대기) 상태로 원장 저장 후 익일 배치로 이관. <br> 2. 장중 시간 + 자동 매매: 원장 상태를 ORDERING(주문 중)으로 선전이 후 비동기 매수 실행 -> 증권사 체결 시 INVESTED 전환. <br> 3. 장중 시간 + 수동 매매: 실제 매수 없이 WAITING_APPROVAL(승인 대기)로 저장 후 투자 권유 푸시 알림 발송. | **[데이터]** 증권사 API 응답 지연을 고려하여, 자동 매매 시 대기열에 진입하는 순간 클라이언트에게는 처리가 완료되었다는 정상 응답을 선 반환함. |
| **FEAT-SYS-005** | 수동 매매 유저 투자 승인 및 만료 처리 | 수동 매매 사용자의 투자 원장을 제어하고, 장기 미응답 건을 청소합니다. | 사용자 설정 is_auto: false | 1. 사용자가 24시간 내에 앱에서 '투자 승인' 요청 시 즉시 증권사 매수 트리거 -> 성공 시 INVESTED 전환 <br>2. 백그라운드 스케줄러가 정기적으로 구동되며 만료 시간(24시간)이 경과한 미응답 건을 EXPIRED(만료됨) 상태로 일괄 변경 | **[시황]** 유저가 승인 버튼을 누른 시점이 '장외 시간'으로 바뀌어 있다면, 즉시 매수하지 않고 PENDING 상태로 변환하여 익일 일괄 매수 배치로 이관함. |
